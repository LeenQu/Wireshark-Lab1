# TCP and UDP Comparison

## Task 1: TCP or UDP and Reasons

| Criteria | TCP or UDP | Reasons |
|---|---|---|
| Reliability and Connection Establishment | TCP | TCP establishes a connection using a three-way handshake and provides reliable data delivery. |
| Data Integrity and Ordering | TCP | TCP ensures that data arrives correctly and in the correct order using sequence numbers and acknowledgments. |

## Task 2: Use Cases and Performance

| Criteria | TCP | UDP |
|---|---|---|
| Use Cases | Web browsing, email, and file transfer | Streaming, VoIP, online gaming, and DNS |
| Performance | Slower because it uses connection establishment, acknowledgments, and retransmissions. | Faster because it has less overhead and does not require connection establishment or acknowledgments. |
